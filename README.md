## 🌟 What is this?

This project helps you understand what makes video games successful! Using data from thousands of games, it can:

- 📊 **Analyze game sales patterns** across different regions and platforms
- 🔮 **Predict sales potential** for new game ideas
- 🎯 **Identify success factors** that matter most
- 📈 **Visualize market trends** with interactive charts

## 🚀 Try it now!

### Quick Start (3 steps)
1. **Download the code**: Click the green "Code" button → "Download ZIP"
2. **Install requirements**: Open terminal and run `pip install streamlit pandas plotly scikit-learn`
3. **Launch the app**: Run `streamlit run app.py`

That's it! The app will open in your web browser.
